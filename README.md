# 🌍 Globe Market — Telegram Mini App

Маркетплейс внутри Telegram: каталог товаров, баннер партнёров, Stories в стиле Instagram, избранное, профиль и админ-панель.

**Деплой:** GitHub Pages (без сервера) · **Каталог, партнёры и Stories:** облако Supabase (бесплатный тариф) · **Настройки профиля:** localStorage · **Админ:** по Telegram User ID (HMAC-подпись)

> Никаких платных сервисов: страница лежит на GitHub Pages, каталог живёт в бесплатном облаке Supabase, уведомления уходят напрямую через Telegram Bot API. Работает без сторонних бэкендов и подписок.

## ✨ Возможности

### Для всех пользователей
- 🛍 **Маркет** — поиск, категории, сетка товаров 2 колонки, детали товара в slide-up шторке, кнопки «Написать в Telegram» и «Instagram». Товары грузятся из облака — их видят все пользователи одинаково
- 🤝 **Баннер партнёров** — на главной под поиском: карточки партнёров с фото, описанием и ссылкой
- 📸 **Stories** — круглые аватары, яркое кольцо = новая, прогресс-бар, тап влево/вправо, свайп вниз для закрытия, видео с mute/unmute, автоудаление через 24 ч. **Истории хранятся в облаке — каждую историю видят ВСЕ пользователи**; фото сжимаются, видео до 25 МБ грузятся в Supabase Storage
- 🤍 **Избранное** — сохранённые товары + счётчик в таббаре
- 👤 **Профиль** — аватар и имя из Telegram, Instagram и «о себе», статистика своих Stories
- 📢 **Рекламный отдел** — 3 тарифа (Stories / Топ маркет / Пакет). Заявка уходит в облако + владельцу в Telegram через Bot API. Статус заявки виден клиенту в профиле и уведомлениях

### Только для админа (по TG ID)
- ➕ Добавление товаров (до 5 фото, цена, категория, район, описание) — **публикация в облако, видна всем мгновенно**
- 🤝 Партнёры — добавление/удаление карточек партнёров на главной (тоже в облако)
- 📦 Управление товарами: редактировать, пометить 🏆 ТОП, удалить
- 📢 Одобрение / отклонение рекламных заявок (клиенту автоматически приходит личное сообщение от бота)
- 📊 Статистика: товары, просмотры, партнёры, новые заявки
- ⚙️ Настройки магазина: Telegram, Instagram, название, описание, баннер главной

**Товары и партнёров публикует ТОЛЬКО админ.** У обычных пользователей нет кнопок «Разместить» / «Продать».

## ☁️ Как устроено облако (Supabase, бесплатно)

- Публичный ключ зашит в страницу — им можно только **читать** каталог/партнёров и **отправлять** заявки на рекламу
- Все изменения (добавить/удалить товар, партнёра, сменить статус заявки) идут через SQL-функцию `admin_api`, которая **проверяет подпись Telegram (HMAC) и ID владельца** — подделать запрос без Telegram-аккаунта владельца невозможно
- `user_api` проверяет подпись любого пользователя Telegram и отдаёт ему только его собственные заявки
- Счётчик просмотров товара — функция `bump_views`

## 🚀 Запуск

1. Открой `index.html` в браузере или задеплой на GitHub Pages:
   ```bash
   git add . && git commit -m "init" && git push
   ```
2. В настройках бота в @BotFather укажи Web App URL: `https://<username>.github.io/globe-market/`
3. Открой бота в Telegram и нажми кнопку Mini App — всё работает
