# 🌍 Globe Market — Telegram Mini App

Маркетплейс внутри Telegram с реалистичным 3D-глобусом (Three.js), Stories в стиле Instagram, избранным, профилем и админ-панелью.

**Деплой:** GitHub Pages (без сервера) · **Хранение:** IndexedDB + localStorage · **Авторизация:** по Telegram User ID

## ✨ Возможности

### Для всех пользователей
- 🌍 **3D глобус на главном экране** — реалистичная Земля с облаками, звёздами, луной и атмосферным свечением. Тап — ускорение вращения и переход в каталог
- 🛍 **Маркет** — поиск, категории, сетка товаров 2 колонки, детали товара в slide-up шторке, кнопки «Написать в Telegram» и «Instagram»
- 📸 **Stories** — круглые аватары, яркое кольцо = новая, прогресс-бар, тап влево/вправо, свайп вниз для закрытия, видео с mute/unmute, автоудаление через 24 ч
- 🤍 **Избранное** — сохранённые товары + счётчик в таббаре
- 👤 **Профиль** — аватар и имя из Telegram, Instagram и «о себе», статистика своих Stories
- 📢 **Рекламный отдел** — 3 тарифа (Stories / Топ маркет / Пакет), заявка уходит владельцу в Telegram через Bot API

### Только для админа (по TG ID)
- ➕ Добавление товаров (до 5 фото, цена, категория, район, описание)
- 📦 Управление товарами: редактировать, пометить 🏆 ТОП, удалить
- 📢 Одобрение / отклонение рекламных заявок
- 📊 Статистика: товары, пользователи, просмотры, избранные, заявки
- ⚙️ Настройки магазина: Telegram, Instagram, название, описание, баннер

**Товары публикует ТОЛЬКО админ.** У обычных пользователей нет кнопок «Разместить» / «Продать».

## 🚀 Запуск

1. Открой `index.html` в браузере или задеплой на GitHub Pages:
   ```bash
   git add . && git commit -m "init" && git push
   ```
   Settings → Pages → Branch: `main` / root → Save

2. В **BotFather**: `/newbot` → получить TOKEN → `/newapp` → URL мини-аппа.

## ⚙️ Настройка

В начале `<script>` блока в `index.html`:

```js
const OWNER_TG_ID = 8396883978;  // твой Telegram ID (уже вставлен)
const BOT_TOKEN   = "";           // токен бота для заявок на рекламу
```

Узнать свой TG ID: @userinfobot.

> ⚠️ **Важно:** токен бота в клиентском коде публичен. Для продакшена лучше проксировать отправку через серверную функцию.

## 🎨 Дизайн-система

| Токен | Значение |
|---|---|
| Фон | `#F5F5F7` |
| Акцент | `#0A84FF` (iOS blue) |
| Золотой (ТОП) | `#FFB800` |
| Текст | `#1C1C1E` / `#8E8E93` |
| Карточки | `#FFF`, тень `0 2px 12px rgba(0,0,0,.08)` |
| Шрифт | Inter / SF Pro Display |

Анимации: переходы 300 ms ease-in-out, карточки fade-up (stagger 50 ms), глобус → миниатюра `cubic-bezier(0.34, 1.56, 0.64, 1)`.

## 🧱 Структура

```
globe-market/
├── index.html   # всё в одном файле: разметка, стили, логика
└── README.md
```

IndexedDB `MarketAppDB`: `listings`, `stories`, `users`, `ad_requests`.
localStorage: `shop_settings`, `user_profile`, `viewed_stories`, `stories_muted`, `favorites`.

> ℹ️ IndexedDB хранит данные локально на устройстве. Это ограничение статического GitHub Pages — для синхронизации между устройствами нужна серверная БД (например Supabase или Base44).
